# Pay the Price

Shared Godot project for Alberta Game Jam 2026.

**Theme: Everything Has a Price.** Your money is your life, ammunition, ability
resource, and final score. Start with $100, survive seven departments, and keep
enough to pay the $50 exit fee. The balance left after leaving is your score.

## Play

Import `project.godot` in **Godot 4.7 or a compatible newer Godot 4 release**,
then press **F6** on `scenes/main.tscn` or **F5** from anywhere. No plugins, paid
assets, C#, or manual scene setup are required.

For the standalone Windows build, extract the downloaded ZIP and run
`PayThePrice.exe`. For the browser build, upload the contents of the Web ZIP to
an HTML5 host such as itch.io, with `index.html` at the ZIP root. The Web preset
uses a single thread and the Compatibility renderer. A local Web build must be
served over HTTP (for example `python -m http.server 8000` inside `build/web`),
not opened as a `file://` URL.

| Control | Action | Initial price |
| --- | --- | --- |
| WASD / arrow keys | Move | Free |
| Mouse | Aim | Free |
| Left click / hold | Shoot | $1 per projectile |
| Space | Dash; briefly avoids damage | $3 |
| E | Use the highlighted object | Shown at the object |
| Escape | Pause / resume; return to title after a run | Free |
| R | Restart the whole run | Free |
| M | Mute / unmute sound | Free |

## The small print

- Reaching **$0 causes immediate bankruptcy**. You cannot spend your last $5 on
  a chest and survive on its payout. The final exit is the deliberate exception:
  exactly $50 pays the invoice and wins with a $0 score.
- Contact with a collector costs $5, with 0.9 seconds of invulnerability after
  a hit. Gold tax collectors take 20% rounded up, with a $4 minimum. Dash through
  danger; it has a 0.8-second cooldown.
- Gold coins recover money. Collect them before leaving a department; doors
  move forward and abandoned rewards stay behind.
- A chest costs $5 and pays one of $2, $4, $5, $7, $10, $15, or $20. Each is
  single-use. Doors never deduct their price twice.
- The three required tolls total $28. In department 3, clear the collectors to
  leave free or pay $15 at the express terminal to skip them.
- Department 4 sells three optional, single-use upgrades: +20% speed ($15),
  a $1 dash discount ($20), and +$2 per defeated collector ($25).
- Department 5 introduces inflation: shots cost $2 and dashes cost $4 before
  discounts. Gold floor panels warn before activating; red panels charge $5
  on contact. Movement remains free.
- At the final gate, an underfunded player can choose **overtime**: survive
  15 seconds for $25. There is no entry fee. It is available only while the
  exit is underfunded, and the temporary collectors disappear when the shift
  ends. This replaces the brief's optional gambling machine with a skill-based
  recovery option. There is no credit/debt system.

The encounters and furniture are hand-authored. The whole room stays visible
with a restrained camera shake on damage. All character art, props, particles,
receipt UI, sound effects, and looping chiptune-style background music are
generated by the project; there are no external audio asset dependencies.
Controller support is not included.

## Edit and tune

- `scripts/ledger.gd`: all money transactions, prices, upgrades, inflation,
  stats, and the atomic exit payment.
- `scripts/player.gd`: exported movement, firing, dash, and cooldown values.
- `scripts/rooms.gd`: seven hand-authored encounters, tolls, rewards, props,
  signs, and hazards. Enemy entries are `[x, y, kind, reward]`.
- `scripts/enemy.gd`: collector, tax man, and runner behavior.
- `scripts/interactable.gd`: chests, doors, shop terminals, and final exit.
- `scripts/game.gd`: scene assembly, transitions, pause/restart, and overtime.
- `scripts/hud.gd` and `scripts/palette.gd`: UI and visual theme.
- `scripts/sound.gd`: original synthesized effects, looping chiptune music, and mute control.

Reusable `.tscn` scenes are in `scenes/player`, `scenes/enemies`,
`scenes/levels`, and `scenes/ui`. Collision layers: 1 player, 2 world,
3 enemies, 4 bullets, 5 reserved for interactables. Bullet sweeps hit only
world/enemy layers, preventing tunnelling or self-damage.

## Validation and export

From the project directory, using a Godot 4.7 executable named `godot`:

```sh
godot --headless --editor --import --quit
godot --headless res://tests/test_runner.tscn
```

The integration suite exercises real scene-tree and physics behavior: money,
movement and diagonal normalization, walls and dashes, projectile hits,
damage cooldowns, drops, single-use transactions, all room transitions,
inflation, pause/restart, overtime, and both endings. It prints a check count
and exits nonzero on failure. Run `tests/capture.tscn` with a graphics display
for visual QA screenshots in `/tmp/pay-the-price-captures` (change its `output`
variable for another OS).

Install matching export templates through Godot's **Editor → Manage Export
Templates**, create the output folders, and use **Project → Export**, or:

```sh
godot --headless --export-release "Windows Desktop" build/windows/PayThePrice.exe
godot --headless --export-release Web build/web/index.html
godot --headless --export-release Linux build/linux/PayThePrice.x86_64
```

Exported builds and caches are ignored by Git. Tests and tools are excluded
from exports. Keep the engine attribution notices with distributed builds;
see `GODOT-LICENSE.txt` and `GODOT-COPYRIGHT.txt`.

## Setup

1. Install **Godot 4.x** and **GitHub Desktop**.
2. Clone this repository in GitHub Desktop.
3. In Godot, choose **Import** and select `project.godot`.
4. Before starting work, **Pull** the latest changes.
5. When finished with a small piece of work, **Commit** it with a clear message and **Push**.

## Team workflow

For a two-person game jam, keep the workflow simple:

**Pull → Work → Save → Commit → Push**

Try not to edit the same `.tscn` scene at the same time. Tell the other person which scene you are working on before making large scene changes.

Prefer small reusable scenes such as:

- `scenes/player/player.tscn`
- `scenes/enemies/`
- `scenes/levels/`
- `scenes/ui/`
- `scripts/`
- `assets/`

This reduces merge conflicts and lets both people work in parallel.

## Commit examples

- `Add player movement`
- `Add enemy chase behaviour`
- `Create level 1 layout`
- `Add title screen UI`
- `Fix player collision`

## Important

The `.godot/` folder is generated locally by Godot and should **not** be committed.

If someone is currently editing a major scene, coordinate before editing that same scene yourself.
